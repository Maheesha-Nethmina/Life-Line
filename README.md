# LifeLine 🏥❤️

**Bridging Generosity and Urgency Through Technology**

LifeLine is a dedicated donation management system tailored for individuals seeking financial support for critical medical operations. This platform connects those willing to give with those in desperate need, ensuring transparency, security, and ease of use.

This project was proudly developed as the **2.2 Semester Group Project** by undergraduates at **Uva Wellassa University of Sri Lanka**.

## 🚀 About The Project

LifeLine isn't just about transactions—it's about creating impact. We realized that many verified medical cases go unfunded due to a lack of visibility and trust. LifeLine solves this by providing a verified, transparent platform where donors can see exactly where their money goes.

### 🌟 Key Features

* **🚑 Urgency-Based Prioritization:** The system automatically highlights and prioritizes medical cases based on urgency, ensuring critical patients get attention first.
* **🔒 Secure Donations:** A secure channel for processing donations with real-time progress updates for every case.
* **🤝 Volunteer Engagement:** A dedicated system for volunteers to help verify case details and support the families in need.
* **💌 Donor Interaction:** Donors can leave messages of hope and blessings, creating an emotional connection beyond just financial support.
* **📢 Public Transparency:** All cases and financial reports are published to maintain high standards of trust and accountability.

## 🚀 Getting Started

To run this project locally, you will need a local server environment like XAMPP, WAMP, or MAMP.

### Prerequisites

* [XAMPP](https://www.apachefriends.org/index.html) (or any PHP/MySQL local server)
* A web browser

### Installation

1.  **Clone the Repo:**
    ```sh
    git clone Life-Line
    ```
2.  **Move to Server Directory:**
    * Copy the project folder into your `htdocs` folder (for XAMPP) or `www` folder (for WAMP).
3.  **Database Setup:**
    * Open **phpMyAdmin** (`http://localhost/phpmyadmin`).
    * Create a new database named `lifeline_db` (or whatever your SQL file requires).
    * Import the `database.sql` file located in the `database/` folder of this project.
4.  **Configure Connection:**
    * Open the database connection file (e.g., `config.php` or `db_connection.php`).
    * Ensure the credentials match your local setup (usually `user: root`, `password: `).
5.  **Run:**
    * Open your browser and navigate to `http://localhost/LifeLine`.
